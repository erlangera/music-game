# Architecture Decision Records

这里记录对架构、数据模型、工具链或团队工作方式有长期影响的决定。普通实现细节不需要 ADR。

## Status Vocabulary

- `proposed`：正在讨论，尚不可作为约束。
- `accepted`：当前决定，后续实现应遵循。
- `superseded`：已被另一条决策替代，保留历史原因。
- `rejected`：评估过但未采用。
