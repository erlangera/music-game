# Music Theory Domain Rules

本页提取实现中最容易被误解的领域不变量。完整课程、题型和判分规则仍以 [`../music-theory-ear-training-prd-v1.md`](../music-theory-ear-training-prd-v1.md) 为准。

## Canonical Vocabulary

| 概念 | 项目含义 | 示例 |
| --- | --- | --- |
| 简谱级数 | 某个调内的音级位置 | `1 2 3 4 5 6 7` |
| 唱名 | 首调唱名 | `do re mi fa sol la si` |
| 音名 | 十二平均律中的音级名称 | `C D E F G A B`、`F#` |
| 音高 | 包含八度的具体声音位置 | `C4`、`A4` |
| 调 | 主音和音阶关系 | C 大调、D 大调 |
| 相对音高 | 结合调性或参考音判断音级 | D 大调中的 A 是 5 |
| 绝对音高 | 无参考音直接判断具体音高 | 直接听出 A4 |

## Invariants

- 产品统一使用首调唱名：`1` 随调变化，不固定等于 C。
- 标准唱名写作 `do re mi fa sol la si`；输入可以兼容 `so`，展示仍使用 `sol`。
- MVP 的目标是相对音高，不把无意训练绝对音高作为成功标准。
- 功能音级和旋律听写题必须先建立调性或提供参考音。
- 当前主音感训练的调性提示由用户手动选择完整音阶、主和弦分解、`I–V–I` 或单独主音；提示只建立上下文，不参与评分或掌握度。
- 十二调主音使用自然大调定义中的固定 `lowTonicMidi`，覆盖 C4–B4。当前不随机八度，同题重播必须复现相同 MIDI 音高；学习页完整音阶另用 C4–B5 演示键盘，以显示上行后的高八度主音。
- 主音感题按十二调、两种题型和 2–7 级干扰音分别使用洗牌袋，避免短轮次中由无约束随机产生明显偏科。
- 当前核心音级听辨只覆盖 `1/3/5`；十二调与三个目标音级分别使用洗牌袋，答题后必须播放 `1 → 目标音` 建立正确映射。
- 第一阶段刻意减少变量：可忽略节奏和八度，每道题只测一个核心能力。
- 题目可以随机，但必须受当前关卡允许的调性、音级集合、音域、长度和重复规则约束。
- 练习与检测不同：练习可以提示和即时讲解，检测限制提示并记录真实掌握度。
- 答错后的反馈应建立正确映射，不应只显示错误状态。
- 自然大调统一使用音级偏移 `[0, 2, 4, 5, 7, 9, 11]`；当前十二个物理主音采用 C、D♭、D、E♭、E、F、F♯、G、A♭、A、B♭、B 的调名和对应调性拼写。F♯大调第 7 级必须写 E♯，不能因物理键相同而写 F。
- 音阶弹奏使用具体 MIDI note，从页面两八度键盘中的低八度主音上行到高八度主音；不能仅比较 pitch class 而忽略顺序或方向。

## Modeling Guidance

- 用不同类型表示 degree、solfege、pitch class 和 concrete pitch，避免全部退化为无约束字符串。
- 题目生成和判分应尽量是可传入种子或固定输入的纯函数。
- 音频播放结果不作为乐理规则的唯一实现；领域答案应能在不启动浏览器音频的情况下测试。
- 调性、音域、题型难度和判分策略应进入显式配置，避免散落在组件条件分支中。

## 节奏入门切片

固定 4/4，四分音符为一拍，八分为半拍；二八是一拍两个八分，不是 2/8 拍。四分音符后半拍延续，八分音符加八分休止后半拍静音，两者起音位置相同。发音位置听写只判起音网格，不推断时值或演奏准确度。数据与规则见 `src/domain/rhythm.ts` 和 [产品范围](../product/rhythm-training.md)。
