# 练习题型多选统一

## 目标

以唱名训练设置为模板，将钢琴键位训练、简谱琴键训练和自然大调训练从“方向/综合模式”单选改为具体题型多选，默认全选且至少保留一种；统一选项卡、圆形勾选图标和题型均衡生成规则。

## 范围

- 钢琴键位：音名 → 琴键、琴键 → 音名两种题型多选，移除“双向混合”。
- 简谱琴键：简谱 → 琴键、琴键 → 简谱两种题型多选，移除整轮固定方向。
- 自然大调：变化音、修复音阶、音级映射、钢琴弹奏四种题型多选，移除“综合练习”。
- 同步领域类型、生成器、测试和产品文档。
- 验证桌面与 320px 设置布局、单选保底、混合出题和完整 `npm run check`。
