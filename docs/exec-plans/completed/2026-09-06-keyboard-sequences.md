## 完成与验证

- 十二音0–11作为物理判分标识，黑键题干和选项独立随机升/降写法，每题12个唯一音高选项；1–12项长度默认1。
- 独立展示控制器按1秒调度，提前答对重置间隔，补答落后项不跳项；版本号拦截过期回调。支持重新演示未答部分，单音目标持续保留。
- 空间键盘输入覆盖白键 A S D F G H J 和黑键 W E T Y U；反向采用按钮与Tab/Enter，避免不完整的自然音快捷键映射。
- npm run check通过：lint、类型、生产构建和6项确定性测试；生成覆盖所有长度与十二音，时钟覆盖自动、提前、落后、重播和停止。
- 浏览器：12项全音高序列逐键答对只记1题；反向3项在不作答时自动演示结束；重播首项答对立即显示第2项；第二项答错首错结束、停止高亮、保留前缀并揭示全部答案。观察到正确琴键G♭与正确选项F♯按等价音对应。
- 320px：12项占位4列，答案4列3行，无横向溢出（clientWidth=scrollWidth=305，innerWidth=320含滚动条）；黑键实际宽25.5px，反馈文字/勾叉可见。未验证真实手机触摸或音频主观听感。
- 浏览器无warning/error；使用独立验证页，保留用户已有未提交代码。未新增依赖、未发布线上。
