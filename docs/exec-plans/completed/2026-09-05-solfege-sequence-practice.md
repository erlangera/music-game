# Extend Solfege Practice Modes

- Status: completed
- Owner: Codex
- Started: 2026-09-05
- Updated: 2026-09-05

## Goal

让唱名训练在进入时可配置 10 题或无限模式，并支持 1–12 项双向序列转换；序列首错立即终止本题，无限模式可主动结束并查看报告。

## Scope

- In scope: 训练设置弹窗、序列题生成与逐项判分、固定/无限会话、响应式与键盘交互、产品文档同步。
- Out of scope: 音频题、持久化设置、逐项答题记录、随机题复现、错题回顾、限时训练和自适应难度。

## Investigation

- 当前组件只建模单个映射，固定预生成 10 题并在完成后结算。
- 现有 PRD 已规划 S3/S4 序列题，但长度上限为 7；本需求将产品上限扩展到 12。
- 项目暂无单元测试或 E2E；最低自动验证门槛为 `npm run check`。

## Decisions

- “难度”在本次范围内显式建模为序列长度，不引入抽象等级。
- 无限模式按需生成题目，只保留常量大小的生成缓冲和统计，避免状态无限增长。
- 整题正确率作为主指标；失败题记录首错位置和正确前缀，但不把未作答后缀伪计为错误点击。
- 答案按钮在一道序列题内保持固定顺序，下一题再洗牌。
