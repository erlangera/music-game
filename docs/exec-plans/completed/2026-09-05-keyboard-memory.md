## 交互决定

- 黑键不发声、不判分、不穿透；反向琴键只展示。
- 找键点击播放所选音高，反向不自动发声；音频失败不阻塞视觉训练。
- 键盘采用空间顺序 A S D F G H J 找键；反向 C–B 字母直接选择音名。作答后锁定，忽略长按。
- 目标以描边/圆点区别于正确的勾号、错误的叉号。减少动态效果时保留静态目标。
- 固定题中途退出返回首页；无限主动结束进入汇总，未答不计分，零题正确率为“—”。
- 首页既有阶段进度为静态原型，不接入掌握度/解锁闭环。
