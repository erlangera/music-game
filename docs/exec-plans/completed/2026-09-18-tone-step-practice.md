# 半音与全音填空练习

- Status: completed
- Owner: Codex
- Started: 2026-09-18
- Updated: 2026-09-18

## Goal

在自然大调模块中新增可独立进入的“半音与全音”专项：给出自然音名或简谱级数，用户组合选择升降号与 C–B / 1–7，填写其上方或下方的半音/全音，并获得即时反馈和单轮汇总。

## Scope

- In scope: 十二音 pitch class 循环、忽略八度、音名/简谱模式、上行/下行、半音/全音、10 题/无限练习、路由与自然大调入口、领域测试与产品文档。
- Out of scope: 严格音程命名与记谱判分、重升重降、音频听辨、跨会话记录、序列题。

## Investigation

- 自然大调第一课已讲授相邻琴键为半音、两个半音为全音，但缺少对应练习。
- 所有练习设置必须复用 `PracticeSetupDialog.vue`；唱名页是视觉与交互参考。
- 现有音高领域以 0–11 pitch class 表示音高类别，适合实现忽略八度的等音判定。

## Decisions

- 作为自然大调模块的独立基础专项，不混入带调性筛选的现有四类大调题。
- 题干只使用自然音名或自然级数；答案选择字母/数字，需要时添加 `♭ / ♯`，未选择升降号即表示自然音。
- 判分只比较 pitch class，因此所有由当前控件可表达的等音答案都接受；反馈同时给出推荐写法与其他等音写法。
