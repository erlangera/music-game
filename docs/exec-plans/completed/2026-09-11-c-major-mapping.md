# 阶段 3：简谱与琴键

- 范围：按用户确认的 Canva 三页稿实现 P0 视觉映射纵向切片；固定 C 大调的简谱→琴键、琴键→简谱，1–12 项、10 题/自由练习、即时反馈及单轮结果。
- 参考：https://www.canva.com/d/BT6BYAsK36hlHZU
- 不包含：五课课程、调性选择、唱名题、听音检测、持久化与解锁。

## 规则

- 默认简谱→琴键、单音、10题。序列每七项覆盖全部音级，跨袋不相邻重复。
- 琴键→简谱自动按每秒一项高亮并播放，可重播未答部分；提前答对推进演示，停止/切页取消演示与声音。
- 首错结束整题，完整答对才计正确；反馈后手动下一题。自由练习未完成题不计入结果。
- 使用共享设置弹窗、页头、钢琴组件与音频控制器；所有会话数据仅在内存。
