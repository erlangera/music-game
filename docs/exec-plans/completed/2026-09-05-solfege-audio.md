# 唱名音频与默写模式

- 范围：默认默写开关、保留题量与序列长度、文字唱名点击播放、默写自动播放与手动中断。
- 播放规则：上一项结束后等待 2 秒；手动播放取消剩余自动序列；切题和退出清理声音与计时。
- 实现：独立音频 composable、复用出题与判分、沿用现有视觉样式。
- 验证：npm run check；浏览器检查默认设置、序列播放中断、反馈、文字模式、320px 与桌面。
- 状态：已完成。
- 验证结果：`npm run check` 和 `git diff --check` 通过；浏览器验证默认开关、四项与无限十二项默写、手动中断、首错反馈、无限汇总与设置保留、文字正反向作答。桌面与 320px 检查布局，320px scrollWidth 为 320；浏览器无 warning/error。
- 音频状态补充验证：临时 Node 脚本以模拟 Audio/计时器验证顺序、结束后 2000ms 间隔、等待中/播放中取消、过期回调、拒绝播放、重试和卸载清理；未新增仓库测试框架。
- 限制：自动播放受限分支通过模拟拒绝验证，未覆盖所有真实移动浏览器的音频策略。
