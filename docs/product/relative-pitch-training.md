# 相对音高主音感与核心音级听辨

- 状态：主音感与核心音级听辨已实现
- 最近核对：2026-09-07
- 路由：`/ear`、`/ear/learn`、`/ear/practice`、`/ear/practice/tonic`、`/ear/practice/degree`

## 当前产品边界

相对音高模块分为学习与练习。学习页解释相对音高和固定音名的区别，使用 C/G 的 `1 → 3` 对比、十二调主音选择、完整音阶和 `5 → 1` 示范帮助用户建立“1 是参照点”的听感。学习页音阶演示钢琴覆盖 C4–B5，确保十二个大调从低主音上行到高主音时，每个实际音高都有对应琴键可见。

练习入口采用四类能力：主音感、音级听辨、音级关系、旋律听写。当前主音感和音级听辨可用；音级关系与旋律听写明确标为后续开放，不能描述为已实现。

主音感训练包含两种交替题型：

- 二选一找主音：调性提示后依次播放两个候选音，选择更像“回家”的一个。
- 钢琴找主音：调性提示后播放未解决的 `3 5 6 5 2`，在 C4–B4 十二音钢琴中选择主音。

每题即时显示正误，随后播放 `5 → 1` 建立正确定位。固定训练完成 10 题；自由练习由用户结束。完成页只显示完成题量，不计算或展示分数、正确率、掌握度、薄弱项或重播评价。

核心音级听辨当前覆盖 `1/3/5`：每题先按用户选择的方式建立调性，再播放一个目标音，用户从 `1/3/5` 中选择音级。答题后显示该调内的实际音名，并播放 `1 → 目标音` 建立正确映射。固定训练与自由练习沿用相同的无评分结果边界。

## 题目与音高规则

- 使用 C、D♭、D、E♭、E、F、F♯、G、A♭、A、B♭、B 十二个自然大调，并复用自然大调领域定义的正确拼写。
- 十二调通过洗牌袋生成；前十二题各调只出现一次，再重新洗牌。
- 两种题型也使用两题洗牌袋；每袋各出现一次，袋内顺序随机。
- 二选一的干扰音从 2–7 级洗牌产生，每六题覆盖一次。
- 主音固定使用各大调的 `lowTonicMidi`，落在 C4–B4；不随机八度。
- C4–B4 仅是练习作答的十二音范围；学习页完整音阶使用 C4–B5 的两八度演示范围。
- 同一题重播保留完全相同的调、题型、候选顺序和实际 MIDI 音高。
- 核心音级题按十二调洗牌，每十二题覆盖一次全部调；目标音级按 `1/3/5` 洗牌，每三题覆盖一次三个音级。
- 核心音级固定使用各调 `lowTonicMidi` 所在八度的音阶音，不随机八度。

## 手动调性提示

用户开始训练前手动选择一种提示，本轮保持不变：

| 提示 | 播放内容 |
| --- | --- |
| 完整音阶 | 上行 `1 2 3 4 5 6 7 1` |
| 主和弦分解 | 依次播放 `1 3 5 1` |
| I–V–I 终止式 | 三个复音和弦 `I → V → I` |
| 只播放主音 | 单独播放 `1` |

提示由用户选择，不自动升级，不参与评价，也不保存等级。

## 音频与交互

- 单音默认约 500ms，音间隔约 80ms，调性建立后暂停约 600ms；候选目标音约 700ms。
- 播放过程中答案控件不可用；完整题目播放结束后开放作答。
- 点击重播会停止当前播放并从头重放同一道题。
- 切换题目、退出或调整设置会停止旧音频。
- 钢琴题作答时先播放用户选择的琴键，再播放 `5 → 1` 定位。
- 音级题作答后播放 `1 → 目标音`；即使答错也只用于即时纠正，不累计评价。
- 音频继续复用应用级钢琴采样、PolySynth 降级和活动琴键高亮。

## 明确不做

- 不做正确率、分数、反应时间、重播次数评价和掌握度。
- 不做错题列表、错题复现、本地持久化、检测和解锁。
- 不做随机八度、麦克风识别、MIDI 输入或节奏题。
- `2/4/6/7` 扩展音级、两音、精选短音型和旋律听写仍是规划能力；短音型未来使用版本控制的精选题库，不完全随机拼接。
