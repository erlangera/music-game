## 统一设置弹窗

训练设置使用共享 `PracticeSetupDialog.vue`，沿用唱名练习的圆角卡片、绿色选中态和遮罩风格。标题、说明和关闭按钮固定在顶部，返回/开始按钮固定在底部，仅中间设置项滚动；适配 320px 窄屏。弹窗打开时背景不可交互，焦点进入标题，Escape 与关闭按钮沿用模块返回路径。原有选项、默认值与重新设置行为不变。

## 产品目的

模块一帮助中文简谱初学者快速建立首调唱名和简谱级数之间的双向映射。规范唱名统一为 `do re mi fa sol la si`；不要重新引入 `ti`。完整术语和领域不变量见 [`../domain/music-theory.md`](../domain/music-theory.md)。

当前练习不考察具体调、音高、节奏或八度，每道题完成一个方向的单项或序列映射。默认开启唱名默写；关闭后使用双向文字训练：

- 唱名默写：播放唱名 MP3，题干隐藏唱名，使用 `1–7` 依次作答。
- 唱名 → 简谱：显示 1–12 个唱名，从顺序固定的 `1–7` 中依次选择答案。
- 简谱 → 唱名：显示 1–12 个简谱数字，从每题洗牌的 `do–si` 中依次选择答案。

## 当前练习蓝图

| 规则 | 当前值 |
| --- | --- |
| 进入设置 | 唱名默写开关（默认开启）、10 题或无限练习、1–12 项序列长度独立生效 |
| 每轮题数 | 固定 10 题，或无限练习直到用户主动结束 |
| 方向配额 | 文字模式：10 题两个方向各 5 题，无限模式按两题一组平衡；默写始终唱名 → 简谱 |
| 连续方向 | 同一方向最多连续 2 题 |
| 映射分布 | 七组映射按洗牌周期生成，分布尽量均衡且相同唱名不连续出现 |
| 按钮内容 | 始终给出覆盖全集的 7 个答案 |
| 按钮顺序 | 数字按 `1–7` 固定排列；唱名每题洗牌，排除正序、倒序和上一道唱名选项题的排列，同一序列内保持稳定 |
| 序列判分 | 每次点击只判当前项；任意一项错误立即终止并判整题错误 |
| 序列转换 | 每答对一项，该位置立即从题干表示切换为对应答案表示；首错后保留已完成转换 |
| 正确反馈 | 完整序列正确后锁定按钮，约 900ms 后自动进入下一题 |
| 错误反馈 | 标出首个错误位置、所选答案、正确答案和完整序列，由用户确认进入下一题 |
| 结果 | 按整题显示正确数、错误数和正确率，可调整设置或使用相同设置再练 |

数字答案选项按音阶顺序生成；唱名答案选项仅在准备新题时洗牌，题目内容和方向仍按原有规则随机。题干使用固定尺寸方块，数字、唱名和喇叭之间切换不会改变宽高或换行位置。

## 输入与可访问性

- 两种题型都支持鼠标和触摸选择。
- 唱名 → 简谱题支持电脑键盘数字 `1–7`；数字直接代表答案语义。
- 简谱 → 唱名题当前不设置字母快捷键，避免 `sol`/`si` 冲突。
- 单项错误或完整序列正确后立即锁定本题按钮，防止重复计分。
- 正误同时使用颜色、图标和文字表达。
- 错题反馈出现后，把键盘焦点移到“下一题”。
- 页面保持可见焦点，所有答案按钮都有可访问名称。

## 页面入口和状态边界

首页“今日推荐”的“开始训练”和学习路径“阶段 01”的“继续学习”都会进入 `/solfege` 路由；退出训练和结果页“返回首页”进入 `/`。路由使用 hash history，因此 GitHub Pages 上的实际 URL 形如 `/music-game/#/solfege`，可直接刷新并支持浏览器前进、后退。

题目、设置、得分和进度只存在组件内存中：刷新、退出或关闭页面后不会保留。无限模式按需生成题目，不建立无限增长的题目队列；用户点击“结束训练”后查看本次汇总。

当前汇总只按整题显示正确数、错误数和正确率。正确前缀与首错位置仅服务于当前题即时反馈，没有形成 PRD `ExerciseAttempt.itemResults` 对应的逐项记录，也没有逐题回顾入口。错题、掌握度、本地存储、可复现 seed、详细训练报告和跨会话学习记录仍属于规划能力。

## 音频与默写交互

- 使用 `public/solfege/{do,re,mi,fa,sol,la,si}.mp3`，不使用 `do_2`。资源地址遵循 Vite base，兼容 GitHub Pages。
- 文字题干中的唱名（含序列答对后转换出的唱名）可点击播放；唱名答案按钮点击时播放所选唱名并提交答案。数字不发声。
- 默写题未完成项只显示喇叭，可访问名称仅包含序号，不泄漏答案；答对项显示数字并保留重听按钮。
- 每题自动顺序播放一次，上一项结束后等待 1 秒。允许边听边答；自动播放期间答对当前项，立即跳到下一待答项播放，跳过剩余音频或等待。若自动播放已到达或超过该项则不重播；手动中断后不会因答对恢复自动播放。
- 手动点击喇叭立即停止当前音频并取消本题剩余自动播放，从头播放选中项，之后不自动恢复。
- 播放期间喇叭声波有动效；减少动态效果偏好下不循环动画。题干播放项额外显示外圈，与当前作答项区分。
- 默写整题判定、切题、结束和卸载时停止声音并取消等待；播放失败显示重试提示，点击喇叭重试。
- 音频副作用由 `src/composables/useSolfegeAudio.ts` 管理，复用单一 Audio 实例，首次播放由开始训练或手动点击触发。

这里是听唱名发音后的数字映射，未实现纯音高听辨；后者仍需先建立调性。

## 实现经验

- 双向混合不要使用“每题独立抛硬币”，否则小样本中可能几乎只有一个方向。应先建立固定的 5/5 方向配额，再洗牌并限制连续数量。
- 答案按钮随机化和题目内容随机化是两个独立约束，应分别建模。
- 反向题不能复用只接受数字的答案类型；当前实现显式区分 `Degree`、`SolfegeName`、`QuestionDirection` 和联合答案类型。
- 单项反馈使用 `唱名 = 数字`；序列反馈显示完整目标答案并指出首个错误位置。
- 正确题自动前进适合保持节奏；错题需要人工确认，保证用户有时间查看正确关系。
- 题目类型、方向生成、平衡音级牌组和基础判分映射位于 `src/domain/solfegePractice.ts`；Vue 组件负责会话状态和交互反馈。
