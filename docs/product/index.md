## Product Promise

音阶阶帮助中文简谱初学者建立以下映射：

```text
简谱级数 1–7 <-> 首调唱名 do–si <-> 音名 <-> 钢琴键位 <-> 实际声音
```

训练采用小步、可检测的学习路径，最终服务于相对音高、短旋律听写和音乐创作。

## Current Implementation Status

截至 2026-09-05，仓库中可确认的实现包括首页/学习路径原型和模块一 S1–S4 的双向文字核心交互：

- 响应式侧栏和顶部导航；
- 今日推荐训练卡片；
- 四个学习阶段的展示状态；
- 周目标、连续学习和提示类本地交互。
- 从今日推荐或阶段 01 进入唱名记忆训练；
- 首页和唱名训练可通过 hash 路由直接访问，并支持浏览器前进、后退；
- 进入训练时可选择固定 10 题或无限练习，并设置 1–12 项序列长度；
- 默认唱名默写：题干以喇叭隐藏唱名，每题顺序播放，间隔 1.5 秒，支持点击重听并中断自动播放；文字模式唱名可点击发声；
- 双向随机题：唱名序列依次选择 `1–7`，或简谱数字序列依次选择 `do–si`；两种答案按钮均随机排列；
- 序列正确项原位转换，首个错误立即终止本题并显示正确答案；
- 整题正确数、错误数和正确率汇总，以及调整设置或使用相同设置再练；
- 320px 起的响应式练习布局。
- 钢琴十二音双向单音/序列：固定 C4–B4 十二音、随机等价写法、隐藏琴键音名、随机音名选项、1–12项双向序列、10题/无限、即时反馈和本轮汇总；由首页阶段02进入。
- 虚拟钢琴黑白键输入与基础 Web Audio 合成音，反向序列每秒自动高亮并支持提前作答推进。

以下 PRD 能力仍是规划，不应在文档或交付说明中描述为已完成：

- S5 限时训练，以及 S1–S4 在完整 MVP 数据模型下的答题记录与复盘；
- 题目 seed/完整随机参数、逐项答题结果、逐题回顾和错题复现；
- 通用音频调度引擎、纯音高听辨与调性建立（唱名 MP3 和钢琴单音合成已实现）；
- 两个八度虚拟钢琴、MIDI 和带节奏的演奏；
- 跨会话判分记录、错题、掌握度与学习记录；
- 本地持久化；
- 阶段检测和解锁闭环。
