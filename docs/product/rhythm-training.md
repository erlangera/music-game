# 节奏入门

## 产品定位与来源

这是原 PRD P2“节奏与节拍”的首个独立切片，由 2026-09-29 用户请求提前实现。原音高训练仍不考察节奏。依据 [研究报告](../deep-research-report.md) 的“恒拍 → 拍内细分 → 休止”顺序和初级第一周前两天练法；报告建议的进度/BPM 不是统一教学标准，原文保留。

## 当前范围

- 首页阶段 06 → `/rhythm` 学习与试听 → `/rhythm/practice` 设置与听写。
- 固定 4/4，以四分音符为一拍；四分、二八、前半拍休止、后半拍休止四种一拍单元。二八不是 2/8 拍。
- 学习页解释恒拍与二分，逐型展示音值、口数和发音位置，四拍预备后播放四次该型，可自行数拍/拍手。
- 听写每题一小节四个单元；基础集合为四分/二八，进阶加入两类八分休止。逐拍均衡使用集合，打乱后形成题目。
- 60（默认）/80/100 BPM，BPM 指四分拍；10题（默认）或无限。复用 PracticeSetupDialog。
- 用户主动播放：高音点击为预备和四分拍，低音为题目；预备后完整一小节，每个网格代表半拍。用户选择所有发音起点，提交后逐格提示漏选/多选。
- 只判发音位置，不判按键时机、音符持续时间或真实演奏能力。四分音符后半拍没有新起音，并不是休止。
- 允许重听、清空和修改，完整听完一次才可提交。音频失败明确提示重试，不将失败计错。
- 答对约 1.2 秒后自动推进；答错需手动继续。主动回放答案取消自动推进。停止、换题、结束、页面隐藏或离开均取消播放；隐藏页面也取消自动推进。
- 整题全对才计正确；提前结束仅统计已提交题目，零题不显示虚构正确率。再练沿用本轮设置，调整设置返回共享弹窗。刷新不保存。
