# C 大调简谱与琴键

- 2026-09-11：阶段 03 的 P0 视觉映射练习；[Canva 三页设计](https://www.canva.com/d/BT6BYAsK36hlHZU)。
- 入口：首页阶段 03“开始练习”、`/c-major`（GitHub Pages `/music-game/#/c-major`）。
- 固定 C 大调 `1=C`，`1–7 ↔ C D E F G A B`，键盘 C4–B4。唱名作为阶段 01 基础，不拆课程或增加唱名题。

## 设置与题目

复用 `PracticeSetupDialog` 固定头尾弹窗。简谱找琴键、琴键选简谱两种题型可多选，默认全选且至少保留一种；每题1–12项；10题或自由练习。10题表示10组序列。

设置内容沿用唱名练习：题型采用一行两列多选卡片，题目数量采用双列单选卡片，均使用右上角圆形勾选；序列长度使用1–12滑块、当前项数及1/4/8/12快捷档位，底部说明逐项作答与首错终止规则。

只从已选题型中出题；选择两种时逐轮随机排序并避免相邻重复，固定10题各5题。每七项覆盖全部音级一次，跨周期没有相邻重复。正向所有数字可见；反向隐藏未答数字、琴键按每秒一项高亮并发声，展示和答题光标独立；提前答对推进当前演示，落后作答不跳过未答项。可重新演示未答部分。单音目标保持至作答。声音不可用仍可视觉练习。

作答前隐藏琴键音名和级数。正向支持鼠标/触摸、Tab+Enter/空格、空间字母快捷键（白键A S D F G H J）；点击黑键判错。反向数字固定1–7排列，支持数字键、按钮点击和键盘焦点操作；琴键只读。

## 反馈与会话

整组完成计一次正确；首错立即结束整题、标记错误位置并揭示完整简谱，提示正确数字与音名、正确琴键。反馈期间锁定答案，手动下一题；末题“查看结果”。可播放完整正确答案。

固定10题中途退出回首页；自由练习主动结束显示结果，未完成序列不计入已答题。零题正确率为“—”。重练沿用设置并清零计数。调整设置后返回保留原会话，点开始会重置本轮。切题、结束、打开设置、失焦及卸载停止演示/声音。

当前仅内存保存单轮正确数、错误数和正确率。无五课课程、检测/解锁、错题持久化、跨调或听音识别。

## 实现与验证

`domain/cMajorPractice.ts` 负责映射、平衡生成和不可变逐项判分；复用 `createHighlightPlayer`、`PianoKeyboard`、`useInstrumentPlayer`。`components/CmajorPractice.vue` 编排会话，`views/CmajorPracticeView.vue` 连接路由。

领域测试覆盖题型多选配额与空选择保护、全部长度、七音覆盖、无相邻重复、黑键拒绝/八度等价及首错/整题锁定。浏览器验证情况见完成的执行计划。
